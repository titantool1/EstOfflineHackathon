# DB 마이그레이션을 받을 위치

DB 설계·시험 결과를 받아 Flyway를 연결할 때 사용하는 예정 위치다. 현재 Flyway 의존성·자동 실행·SQL은 추가하지 않았다. 이 디렉터리가 있다고 DB 구성이 완료된 것은 아니다.

스키마가 정리되면 다음을 한 작업에서 맞춘다.

1. 인증 사용자 ID, 공통 지역/행동 ID와 테이블 소유권 확인.
2. 기존 DB와 새 DB 적용 경로 결정, Flyway 의존성/설정 추가.
3. 승인된 변경을 버전 SQL로 추가하고 어댑터·조회 DTO·응용 처리 연결.
4. 빈 DB 생성과 기존 상태에서의 변경을 검증.

적용된 버전 SQL은 덮어쓰지 않고 후속 버전을 추가한다. 실제 개인정보·비밀번호·운영 DB 덤프를 이 폴더에 넣지 않는다. 구체적인 테이블명과 버전 번호는 현재 진행 중인 DB 작업과 맞춘다.
