# QA 처리 현황과 Git 통합 범위

2026-09-18 갱신. **화면·인증·미션·지도·챗봇 매장검색 QA 수정이 공유 환경에 반영됐고, 별도 통합 브랜치에서 검토와 실행 검사를 마쳤다.** 메모리는 별도 작업 진행 중이며 이미지는 사용자가 확인했다. [이번 통합 범위와 검사](qa-integration-2026-09-18.md)를 커밋·머지 기준으로 사용한다.

## 현재 배포와 통합 기준

- 이번 통합 기준 웹: `eco-jupjup-team-frontend:qa-chat-places-v2-20260918`. 머지 직전 관측한 현재 웹은 별도 후속의 `qa-signup-home-20260918`이다.
- QA 백엔드: `eco-jupjup-team-backend:qa-mission-inline-v2-20260918`.
- 통합 시작점: `main`/`origin/main`의 `62b1695`. 원격과 같았으나 QA 수정125파일이 미커밋이었다.
- 통합 브랜치: `work/qa-integration-20260918`. 시작 시 코드·테스트107파일은 배포본과 일치했고 나머지18파일은 문서·장소자료였다. 이후 이번 통합 기록을 추가했다.
- 최신 매장검색까지 같은 묶음으로 포함한다. 이전 표의 ‘매장검색 배포 전’과124파일 집계는 당시 관측이며 지금 상태가 아니다.
- 진행 중 메모리와 새 문구 수정은 통합 고정 이후 작업본에 생기더라도 덮어쓰지 않는다. 사진은 사용자 확인 상태이며 오판정이 코드로 수정됐다는 뜻은 아니다.

이번에는 이 배포 소스로 실제 통합 검사까지 마쳤다. main 반영은 테스트한 커밋의 fast-forward로 수행하며 공유 QA 재배포·원격 push와 구분한다. 최종 커밋 식별은 `git log`와 작업대의 [main 반영 기록](../../codex-harness-lab/evidence/eco-qa-merge-2026-09-18/README.md)을 따른다.

## 검사 근거를 읽을 때

이번 통합 고정본의 프론트240검사·타입·전체 src/tests 린트·프로덕션 빌드, 실제 일회용 PostgreSQL을 포함한 백엔드111검사가 모두 실패/skip0으로 통과했다. 통합 Next+Spring+PG 브라우저 인증30항목·미션/레벨10항목도 확인했다. 원래 공개 지도 네트워크 대기에서 중단된 마지막 부분만 화면 준비 기준으로 재검사했으며 최초 실패 로그도 보존한다.

매장검색 실제 모델·공유HTTPS 검사는 [배포 당시 결과](../../codex-harness-lab/evidence/eco-chat-place-gap-2026-09-18/deployment/README.md)다. 이번 통합에서 실제 모델·지도 SDK·사진 모델을 새로 호출하지 않았다. 서로 다른 판본의 검사 수를 합산해 전체 통과 수로 취급하지 않는다. 전체 QA 무결함이나 진행 중 메모리 수정의 완료를 뜻하지 않는다.
