# QA 후속 통합 마감

2026-09-18. 첫 통합 `9ece89c` 이후 완료된 UI·조건 메모리 변경을 `work/qa-closeout-20260918`에서 고정했다. 사용자 재개 지시에 따른 커밋·로컬 main 통합이다. 기존 QA 배포를 사용하며 이번 통합에서 DB 이관이나 재배포·원격 push를 추가하지 않는다.

## 포함한 변경

- 미션 조건: 검토한 3제도의 필수·중 하나·제외·우대 구분과 조사 메모11개 표시 보완.
- 미션 장소: 기존 Kakao 지도에 해당 미션의 등록 좌표만 표시하고 목록·주소·원래 카드 복귀 연결. 종료·좌표 미확인 장소는 지도에서 제외.
- 관심사: 미설정이면 설정, 저장값이 있으면 수정 문구. 헤더의 지역 선택 제거, 관심사 화면의 알아볼 동네 유지.
- 가입: 성공 후 자동 로그인하고 `/onboarding` 관심사 선택으로 이동. 기존 로그인 복귀 경로 유지. 이전 가입홈 검사는 당시 판본 기록이다.
- 조건 메모리: 본인16항목 시작 조회, 매 턴 구조화·코드 검증·동일값 비교, 답변 성공 후 메모리 채택, 종료 시 기존 암호화 DB에 저장하고 다음 상담에서 재조회. 독립 확정값과 모호한 항목의 되묻기를 함께 처리한다.

DB 스키마는 기존 V13을 유지한다. 이번 백엔드 변경은 본인 조건 조회와 관련 검사이며 새로운 이관 파일은 없다. 메뉴 순서 변경은 고정 후 별도 진행 중이므로 이번 커밋에서 제외하고 공유 작업본을 보존한다.

## 검사 근거

최종 프론트는 `qa-signup-onboarding-20260918`, 백엔드는 `qa-condition-memory-20260918`의 검사본과 총353파일이 일치한다. 해당 프론트 빌드 이미지에서 전체248검사·전체 src/tests 린트·타입 검사를 다시 통과했다. 프로덕션 빌드는 같은 소스의 가입 QA 빌드 로그를 사용한다.

백엔드는 소스가 그대로여서 실제 임시 PostgreSQL의112검사(실패·오류·skip0)를 재사용했고 원시 XML을 재집계했다. PlaceDatabaseTest는 별도 DB 실행 결과를 사용하며 이미지 빌드 때 남은 skip 보고서는 제외했다. 기존 UI 통합14+5항목에서 가입홈 항목은 이후 가입관심사 QA의 실제5항목으로 대체한다. 조건 표시·관심사·미션 시작/완료·레벨 검사는 해당 소스가 같아 유지한다.

조건 메모리는 실제 모델·DB의 후보8턴/20항목과 배포8턴/20항목에서 혼합발화·되묻기·정정·상담 중 DB 미변경·종료 저장·새 상담 재조회를 확인했다. 전체 자연어의 정확도를 보장하는 시험은 아니다. 미션 지도 실제 SDK9항목과 헤더 실제9/대역2항목도 각 배포의 근거를 연결했다. 서로 다른 검사 수를 합산해 하나의 전체 통과 수로 쓰지 않는다.
