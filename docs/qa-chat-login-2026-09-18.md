# 챗봇 로그인 안내와 복귀 QA

일반/미션 챗봇에서 로그인 여부를 확인하고, 필요한 경우 로그인 버튼을 제공한다. 로그인 성공 후 요청했던 상담 화면으로 돌아가며 미션 번호와 카드 복귀 위치도 보존한다. 사용 중401은 재로그인 안내, 일반 연결실패는 재시도로 구분한다. 홈 로그인은 홈, 관심사 수정의 로그인은 수정 모드로 돌아온다. 허용한 내부 경로만 복귀 대상으로 사용하며 자동 질문 재전송은 없다.

QA 웹은 `eco-jupjup-team-frontend:qa-chat-login-20260918`이다. 기존 새로고침 복원·미션 추천/완료·동네 인증·지도 변경을 보존했다. 다른4서비스는 그대로이며 모두 healthy다. 전체222검사·린트·타입·빌드·대역9흐름·실제회원6흐름·공유주소 화면 검사를 통과했다. 실제 모델 호출은 없고 시험 회원/사용자 잔여0, 임시 검사 컨테이너 잔여0이다. 소스8파일을 제품 작업본에 반영했으며 main 커밋/push는 하지 않았다.

고정 릴리스와 재기동용 override는 작업대 `.local/releases/20260918-chat-login/`에 있다. 실제 Compose 조합/원복 명령은 `evidence/eco-chat-login-2026-09-18/compose-before.json`, `rollback-command.json`, `deploy.py`를 따른다. 이후 다른 작업이 배포했다면 그 최신 구성을 우선한다. API 키는 명령/문서에 기록하지 않는다.

후속 챗봇 배포는 `ChatAuthentication.tsx`, ChatPanel/미션진입의 인증만료 연결, `login-return.ts`의 쿼리 보존을 함께 유지한다. 새로고침 복원과 이번 로그인 흐름은 제품 소스에서 병합돼 있다.
