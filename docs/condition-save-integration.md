# 조건 저장 연결 통합검증

2026-09-18, `work/condition-save-connected`에서 암호화·조건 저장 기반 `b2e7878`과 main `b0bfbe8`(스트리밍·반응형·미션 V11)을 합쳤다. 상담 종료 저장용 V12를 포함해 다음을 확인했다.

| 검사 | 결과 |

| 프런트 전체 | 174개 통과, 실패·skip 0, 전체 린트 통과 |

자동 종료는 단조 증가 시계로 90.26초에 확인했다. 시험 중 시스템 시계가 뒤로 이동해 첫 `Date.now()` 측정이 짧게 나온 기록도 보존했다. 브라우저 첫 검사의 요청 관측 경합은 응답 완료를 기다리도록 검사기를 고쳤다. Docker에서 Mockito 동적 attach가 멈춘 문제는 테스트 JVM에 명시적인 Mockito javaagent를 전달해 해소했다. 제품 동작을 우회해 통과시킨 것은 아니다.

독립 검토에서 발견한 잘못된 입력/충돌의 500 응답과 생성 중 종료 경합을 수정했다. Main은 비본인 생년월일 키, 지역 집합 baseline 비교, 실제 검사 출력과 최종 변경을 추가 확인했다. 생성 중 수동 종료 회귀를 포함한 독립 프런트 검사 18개도 통과했다.

## 범위와 배포 전 단계

검사에는 합성 회원·키·격리 DB를 사용했다. 대화 검사는 모델·카탈로그 대역과 실제 Spring·DB를 연결했고, 브라우저 검사는 종료 API 대역 및 가상 시계를 사용했다. 외부 모델 성능, 운영 프록시, 운영 DB와 운영 키, 배포 이미지 전체 실행은 이 결과의 보장 범위가 아니다.

코드·이관의 통합검증은 끝났지만 main 반영·원격 push·운영 배포는 수행하지 않았다. 배포 담당은 이 브랜치의 검증본을 반영하고 [개인 사실 보호 저장](private-facts-storage.md)의 키 준비·백업·V8~V10 유지보수 이관 절차 및 V11/V12 적용을 실행 환경에서 확인해야 한다. 기능 정책은 [상담 종료와 조건 저장](condition-save.md)에 있다.

실행 로그·검사 스크립트·보고서·화면·소스 SHA256·검토 기록은 작업대 `evidence/eco-condition-save-connected-2026-09-18/`에 보존한다.
