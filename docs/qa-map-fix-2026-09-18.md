# 지도 장소 검색 연결 QA 수정

현재 웹·Spring 이미지는 `qa-map-20260918`이다. 이전 `qa-places-20260918`의 장소 이관 V13·동네검색·기존 미션 기능을 포함하고, 지도 제목과 장소 검색 API 연결을 보완했다. 소스는 미커밋이며 push하지 않았다.

기존 Next POST `/api/places`가 중지된 FastAPI 서버를 호출해503을 반환하던 문제를 팀 Spring GET `/api/places`→PG `app.place.metadata` 조회로 수정했다. 기존 `SPRING_BASE_URL`을 사용하며 환경변수·새 migration은 없다. API는 단어 모두 포함 검색·거리순 최대40곳·반경최대100km를 지원한다. 화면은 기존 서울중심30km 기준이며 사용자 위치·관심사 개인화는 추가하지 않았다. 좌표 누락/불량·모든 연결이 closed인 장소는 제외한다. 후보 장소의 영업·혜택은 확정하지 않는다.

지도 제목은 “친환경 실천을 위한 내 주변 맞춤 지도”. 실제 검색 기준인 서울중심30km 설명은 유지했다.

검사: backend 지도4개(실제 이관자료PG검사 포함)·frontend 지도/호출제한16개·타입·범위린트 통과. 이미지 빌드필수 frontend106개·린트/타입/빌드 통과. backend 이미지103개 중6개 환경의존 검사 skip, 실패0이며 별도 지도4개는 skip0다. 격리환경과 QA보호프록시 경유 실제배포 모두 초기40곳·성동구 개인컵13곳·빈검색200·모바일390px·pageerror0 확인. Kakao SDK 타일/길찾기와 외부터널 로그인은 이번 새 검사 범위가 아니다. 다른3서비스 컨테이너ID 동일·5서비스healthy·318소스파일과 고정릴리스 일치 확인.

고정 소스: `.local/releases/20260918-map-connect/`. 제품 루트에서 재기동:

```sh
docker compose --project-directory "$PWD" --env-file .env -p eco-jupjup-team -f .local/releases/20260918-f54b22f/docker-compose.yml -f .local/releases/20260918-f54b22f/release.override.json -f .local/releases/20260918-map-connect/release.override.json --profile app --profile ai up -d --no-build --no-deps --wait backend frontend
```

이 지도 수정만 원복하려면 마지막 override를 `.local/releases/20260918-place-mapping/release.override.json`으로 바꿔 두 서비스만 교체한다. DB V13은 유지한다. 원복 시 예전 지도검색503도 돌아온다. 기존 장소/암호화 이관을 되돌리는 절차와 혼동하지 않는다.
