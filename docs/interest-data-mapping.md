# 관심사와 검색 데이터 매핑

온보딩의 관심사 ID를 Elasticsearch 문서의 `interest_ids`와 연결한다. 한 데이터가 여러 관심사에 해당하면 복수 ID를 유지하며, 추천 시 사용자가 고른 ID 중 하나 이상이 일치하는 문서를 후보로 사용한다.

| 관심사 ID | 화면 이름 | 대표 제도 |
| --- | --- | --- |
| `green-mobility` | 교통비·친환경 이동 | G003, G008, SDG-ZEV-2026, G007 |
| `green-shopping` | 친환경 쇼핑·장보기 | G004, G034, G035, G024, KR-CNP-GREEN-2026 관련 행동 |
| `energy-saving` | 전기·난방비 절약 | G021, G031, G048, G070, G075, G080, SEOUL-EM-BLDG-2026 |
| `home-upgrade` | 집·가전 개선 | G022, G027, G047, G101, SDG-FOOD-REDUCER-H2-2026 |
| `waste-reduction` | 재활용·쓰레기 줄이기 | G038, G042, 자원순환·다회용기·음식물 감량 데이터 |
| `eco-learning` | 환경 체험·배우기 | G002, G039, G117, G007, 환경교육·퀴즈·행사 데이터 |
| `unsure` | 아직 잘 모르겠어요 | 자격조건이 적은 G007, G008, G024, G035, G038, G042, G117 |

장소 17,601건은 `place_type`으로 분류한다. 따릉이 대여소는 이동, 카페·베이커리·제로웨이스트 상점·리필판매기는 쇼핑, 수거함·재활용정거장·무인회수기·제로식당 등은 쓰레기 줄이기에 연결한다. 정책과 행동은 제도 ID, 행동 ID, 카테고리와 이름을 함께 사용한다.

현재 중복을 포함한 관심사별 문서 수는 다음과 같다.

- 교통비·친환경 이동: 3,467건
- 친환경 쇼핑·장보기: 4,734건
- 전기·난방비 절약: 17건
- 집·가전 개선: 9건
- 재활용·쓰레기 줄이기: 14,365건
- 환경 체험·배우기: 28건

추천 API는 대표 제도를 우선 후보에 포함하면서 나머지 매핑 데이터도 세션별로 섞는다. 프론트엔드는 같은 관심사 사용자의 노출·상세 확인·선택·완료 수와 20% 탐색 규칙을 적용해 한 번에 한 건을 보여준다. 따라서 초기 인기 데이터만 계속 고정되는 문제를 줄인다.

매핑을 다시 적용하려면 Elasticsearch 실행 후 다음 명령을 사용한다.

```bash
.venv/bin/python scripts/sync-interest-mapping.py
```

`database/fixtures/catalog/schemes.json`에 새 제도를 추가했고 해당 제도가 검색 인덱스에 아직 없다면 임베딩 모델을 사용할 수 있는 환경에서만 `--include-catalog`를 추가한다.
