# 제출 소스 안내

2026-09-18 최종 QA 통합 소스다. 프론트·백엔드·DB 이관/공개 기초자료·실행 스크립트·설정 예시·문서를 포함한다. 최종 main 커밋을 `git archive`로 ZIP으로 만들며 Git 이력, 실제 API 키, 개인 환경설정, 설치 의존성, 빌드 결과물, 운영 DB/회원정보는 포함하지 않는다.

## 최신 기능 기준

- 로그인은 일반/챗봇/미션 경유 모두 홈으로 이동한다. 회원가입 직후는 관심사 선택이다. 예전 원화면 복귀 설명보다 이 기준이 우선한다.
- A17 다회용기 음식 사진이 met이면 기존 자기보고 완료 API로 앱 미션 완료를 기록한다. 저장 성공 뒤 카드/레벨 갱신, 부적합/확인불가 미완료, 저장실패는 사진 재분석 없이 동일 이벤트 재시도와 기존 완료 조회로 처리한다. 공식 참여 실적/포인트 지급은 별개다.
- 이전 QA의 조건 메모리·종료 저장/재조회·미션/조건 표시·지도 기본값·관심사·메뉴·로그아웃 수정도 포함한다.

## 실행

저장소 루트 [README](../README.md)의 기반 환경 실행 절차를 따른다. Docker Compose/Python3와 안내된 Node 환경을 사용한다. 설정 항목은 `.env.example`·`frontend/.env.local.example`에 있으며 실제 API 키는 비워 두었다. AI·카카오 연동을 실행하려면 실행자가 해당 키를 별도 설정한다. 암호화 키는 [개인 사실 저장 안내](private-facts-storage.md)에 따라 Git 밖에서 준비한다. 기존 운영 DB나 시연 계정 정보는 제출하지 않는다.

## 확인 범위

최종 프론트 전체254검사·전체 src/tests 린트·타입·프로덕션 빌드 확인. 백엔드는 코드 변경이 없어 실제 임시 PostgreSQL112검사(실패/오류/skip0)를 재사용했다. 로그인 실제5흐름, 사진 완료 후보7/상세3항목, 배포 후 실제 음식 사진1장의 met→완료/Lv.2→새로고침count1을 확인했다. 사진 대역을 사용한 오류경계 검사와 실제 모델 검사는 구분한다.

닫힌 용기/가림 사진 판정 한계, 전체 자연어 표현의 정확성, 지도 기본값 후속의 실제 SDK 타일 확인 제한은 남아 있다. 모든 상황의 품질을 보장하는 전수검사는 아니다. [QA 현황](qa-status-2026-09-18.md)·[사진 완료](qa-photo-completion-2026-09-18.md)·[조건 메모리](qa-condition-memory-2026-09-18.md)에 범위를 정리했다. 일부 과거 문서의 별도 작업대 근거 링크는 이 소스 ZIP 외부 자료다.
